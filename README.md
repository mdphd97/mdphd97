## 🌟 Featured Open Source Project

### 📡 [DepRadar](https://github.com/mdphd97/depradar)
*Interactive System & Package Dependency Radar for Developers and AI Agents.*

[![PyPI Version](https://img.shields.io/pypi/v/depradar?logo=pypi&logoColor=white&color=blue)](https://pypi.org/project/depradar/)
[![PyPI Downloads](https://img.shields.io/pypi/dm/depradar?color=informational)](https://pypi.org/project/depradar/)
[![CI](https://github.com/mdphd97/depradar/actions/workflows/ci.yml/badge.svg)](https://github.com/mdphd97/depradar/actions/workflows/ci.yml)
[![Live Demo](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-38BDF8?logo=github)](https://mdphd97.github.io/depradar/)

DepRadar turns workstations into an interactive force-directed visual network map. It scans Python virtual environments, AST import manifests, Node runtimes, and system packages—sizing components by storage footprint and providing a native **Model Context Protocol (MCP)** server for AI assistants like Claude Desktop and Cursor.

```bash
# Try it instantly without permanent installation
uvx depradar
```
